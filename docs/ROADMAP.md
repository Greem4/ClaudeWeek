# Чего не хватает

Честный список пробелов на 2026-08-05. Не «идеи на будущее», а то, чего в
приложении сегодня нет, — с ценой вопроса и тем, что мешает сделать.

Порядок — по тому, насколько заметно отсутствие в ежедневной работе.

---

## Заметно сразу

### 1. Уведомлений нет

О приближении к лимиту сообщает только цвет — иконки и заголовка. Если панель
не открывать, а строку меню не разглядывать, момент «осталось 10 %» пройдёт
мимо.

*Что делать:* `UNUserNotificationCenter` на переходах `LimitState`
(`onTrack → overPlan → critical → exhausted`), с порогами из настроек и
защитой от повторов внутри одного окна недели. Точка подключения уже есть —
`LimitState` в `Snapshot.swift` заведён ровно под это.

*Цена:* полдня. *Мешает:* ничего, кроме желания не превращать виджет
в источник шума — поэтому по умолчанию уведомления должны быть выключены.

### 2. История не копится

Прошлые недели нигде не хранятся: `cache.json` держит только текущее окно.
Сравнить «эта неделя против прошлой», увидеть тренд или средний темп нельзя.

*Что делать:* дописывать в отдельный `history.json` итог недели в момент
сброса (границу видно по `WeekWindow`), хранить 8–12 записей, показывать
спарклайн в футере панели.

*Цена:* день с UI. *Мешает:* ничего.

### 3. Автозапуск ставится скриптом

`install-agent.sh` пишет LaunchAgent. Переключателя «запускать при входе» в
настройках нет, и состояние автозапуска в окне не видно.

*Что делать:* `SMAppService.mainApp` (macOS 13+) — регистрация без скрипта,
плюс показ статуса. Придётся решить, кто главный: `SMAppService` и
LaunchAgent из скрипта будут конфликтовать, поэтому переезд должен быть
полным, со снятием старого агента при первом запуске новой версии.

*Цена:* полдня вместе с миграцией.

## Заметно в углах

### 4. Пятичасовая сессия офлайн не считается

Локальный источник её не вычисляет: веса моделей приближают недельную
формулу, а не сессионную. Офлайн показывается последнее официальное значение
и только пока не истекло его окно — потом строка исчезает.

*Что делать:* либо честно оставить как есть (текущее решение), либо
калибровать вторую формулу по официальным ответам так же, как недельную.
Второе — исследование на несколько дней с риском выдумать точность, которой
нет.

### 5. VoiceOver не прослушан вживую

Разметка есть: у каждой строки свой ярлык, у панели — сгруппированный
заголовок. Ушами это никто не проверял, и порядок обхода может оказаться
неудобным.

*Что делать:* включить VoiceOver, пройти панель и настройки, поправить
`accessibilityLabel` и порядок. Полчаса работы, которую нельзя
автоматизировать.

### 6. Тесты не покрывают UI

XCTest без Xcode недоступен, поэтому проверки написаны своим раннером и
охватывают ядро: окно недели, план, форматирование, оба провайдера, конфиг.
Всё, что рисует, проверяется глазами через `--screenshot` и установку.

*Что делать:* снапшот-тесты панели через `ImageRenderer` с эталонными PNG —
`--screenshot` уже умеет рисовать всё нужное, осталось сравнивать с эталоном
и падать на расхождении.

*Цена:* день. *Мешает:* эталоны придётся обновлять при каждой правке вёрстки.

### 7. Настройки не покрыты тестами

`Config` проверен, а логика окна — нет: применение на лету, дебаунс записи,
пересоздание провайдера при смене источника. Ошибка здесь тихая: настройка
«применилась», но до провайдера не дошла.

*Что делать:* вынести `applyFromSettings` в тестируемый тип без AppKit
и проверить, какие поля пересоздают провайдер.

## Ограничения, с которыми живём

### 8. Эндпоинт не документирован публично

`/api/oauth/usage` снят с живого ответа и с клиента. Схема может измениться
без предупреждения. Декодер написан так, чтобы пропажа поля давала честную
ошибку, а не молчаливый ноль, и приложение уходило на локальную оценку —
но в этот момент точность падает до калибровки.

*Страховка:* `swift Scripts/probe-usage.swift` печатает живой ответ целиком;
запасной путь через `limits[]` уже есть.

### 9. Автообновления нет

Новая версия ставится тем же `install-agent.sh`. Ни проверки версии, ни
уведомления о выходе новой.

*Что делать:* Sparkle требует подписи и площадки для appcast; для проекта,
который ставится из исходников, достаточно было бы сравнения версии с
последним тегом git при запуске.

### 10. Только один аккаунт за раз

Токен один — либо из Claude Code, либо свой. Показать два аккаунта рядом
(рабочий и личный) нельзя.

*Что делать:* список источников вместо одного и переключатель в панели.
Работы на день, но польза сомнительна, пока никто не попросил.

### 11. Локализация только русская

Тексты вшиты в код по-русски. Английской версии нет.

*Что делать:* `String(localized:)` и `.strings`, если появится нужда.

## Что сознательно не делаем

- **Виджет Центра уведомлений** — требует App Groups, а та доступна только по
  платной подписке Apple Developer Program, которую из РФ штатно не оплатить.
  Разбор — в приложении Б [плана](PLAN.md).
- **Обновление OAuth-токена.** Refresh-цикл — дело Claude Code; два процесса,
  наперегонки меняющие одну запись Keychain, теряют токен. На `401` мы уходим
  на локальную оценку и ждём, пока Claude Code обновит токен сам.
- **Красная заливка полосы.** Красный и зелёный неразличимы при дейтеранопии,
  поэтому красный живёт только в заголовке и иконке, рядом со словом и знаком.
