# ClaudeWeek

Меню-бар приложение для macOS: недельный лимит Claude Code одним взглядом.

На каждой полосе два цвета — **план** (сколько допустимо потратить к этому
моменту) и **факт** (сколько реально потрачено). Видно не только «сколько
осталось», но и «иду я в графике или обгоняю».

```
строка меню:  ▍▍▍▍░░ 64%
              ↓ клик
┌──────────────────────────────────────────────────────────┐
│  ЛИМИТ НЕДЕЛИ    сброс ПТ 15:00        ≈14 % в сутки     │
│  ПТ  ███████░░░░░░░░░░░░░░                  7 / 7 %      │
│  СБ  ██████████████▒▒▒▒▒▒░                 15 / 21 %     │
│  ПН  ██████████████████████████████▓▓▓░    58 / 50 %     │
│  осталось 42 % · сброс через 3 дн 6 ч · темп 1.2×        │
└──────────────────────────────────────────────────────────┘
```

`█` факт · `▓` перерасход · `▒` остаток плана · `░` вне плана

## Установка

```bash
./Scripts/make-app.sh        # собирает dist/ClaudeWeek.app
./Scripts/install-agent.sh   # ставит в ~/Applications и включает автозапуск
```

Приложение появится в строке меню. Снять — `./Scripts/uninstall-agent.sh`.

### Калибровка

Пока приложение не знает, чему равны 100 % вашего лимита, оно показывает `—`.
Выполните `/usage` внутри Claude Code и передайте увиденное число:

```bash
~/Applications/ClaudeWeek.app/Contents/MacOS/ClaudeWeek --calibrate=64
```

Приложение посчитает условную стоимость недели по транскриптам, поделит на долю
и запишет `weeklyBudget` в `~/.config/claude-week/config.json`. Дальше оценка
держится близко к официальной; перекалибровать можно в любой момент.

## Что уже работает

- **Локальный источник** — расход считается по `~/.claude/projects/**/*.jsonl`:
  токены взвешиваются по ценам моделей, записи из `subagents/` дедуплицируются
  по `uuid`, файлы читаются инкрементально (полный проход 193 файлов — 1.3 с,
  повторный — 0.04 с).
- **Панель недели** — семь двухцветных полос, светлая и тёмная темы, разметка
  для VoiceOver (вживую ещё не прослушана), уважение к «Уменьшению движения».
- **Жизненный цикл** — обновление по таймеру, пауза на время сна, реакция на
  пробуждение и смену таймзоны, перечитывание конфига после правки.
- **Автозапуск** — LaunchAgent, приложение живёт только в строке меню
  (`LSUIElement`), без иконки в Dock.

**Официальный источник (`/usage`) пока не подключён** — эндпоинт не
документирован, и его разведка требует живой сессии `claude --debug api`.
До этого момента цифра помечается как оценка: `≈64%`. Подробности — в
[docs/PLAN.md](docs/PLAN.md), этап M3.

## Командная строка

```
ClaudeWeek                 запустить приложение в строке меню
ClaudeWeek --json          состояние недели в JSON (дни, стоимость, темп)
ClaudeWeek --calibrate=N   подогнать оценку под официальные N %
ClaudeWeek --screenshot К  отрисовать панель в PNG в обеих темах
ClaudeWeek --config=ПУТЬ   свой файл конфигурации
ClaudeWeek --provider=X    источник данных: local (official будет в M3)
ClaudeWeek --icon К        сгенерировать .iconset (вызывается из make-app.sh)
ClaudeWeek --verbose       подробный лог в stderr
```

## Требования

- macOS 14+
- Command Line Tools (`xcode-select --install`) — полный Xcode не нужен
- Установленный и авторизованный Claude Code
- Ни Apple ID, ни платной подписки разработчика не требуется

## Настройки

`~/.config/claude-week/config.json` — читается при старте и после правки:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `resetWeekday` / `resetHour` | `6` / `15` | момент сброса: пятница 15:00 |
| `timeZone` | `Europe/Saratov` | таймзона окна |
| `refreshInterval` | `300` | секунды между обновлениями, минимум 30 |
| `provider` | `auto` | `local`, `official` или `auto`; до этапа M3 всегда работает `local` |
| `planAnchor` | `midDay` | опорная точка плана: `midDay` или `endOfDay` |
| `menuBarStyle` | `percent` | `percent` или `compact` (только полоска) |
| `weeklyBudget` | `0` | условная стоимость недели; ставится калибровкой |
| `thresholds.warn` / `.critical` | `1.0` / `0.9` | когда полоса желтеет и когда краснеет заголовок |

## Принятые решения

Сброс лимита — пятница 15:00. Уведомлений нет, о перерасходе сообщает только
цвет. План считается на середину суток (ряд 7/21/36/50/64/79/93/100), опорная
точка переключается одной строкой конфига.

Форма подачи — выпадающая панель из строки меню, как у Stats или iStat Menus.
Виджет Центра уведомлений рассматривался и отклонён: он требует App Groups, а та
доступна только по платной подписке Apple Developer Program, которую из РФ штатно
не оплатить. Разбор — в [приложении Б плана](docs/PLAN.md).

Подробный план работ, модель данных и разбор рисков — [docs/PLAN.md](docs/PLAN.md).
